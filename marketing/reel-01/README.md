# AstroVidya Reel #1 — launch (Hindi, 38s, 1080×1920)

Voice-over and images were made in ElevenLabs (flow "AstroVidya launch reel");
on-screen Hindi text is rendered by Chromium (`overlays.mjs`) and the video is
assembled with ffmpeg (`build.sh`). To rebuild: put voice.mp3 and s1–s5.png
here, run `node overlays.mjs`, then `bash build.sh`.
